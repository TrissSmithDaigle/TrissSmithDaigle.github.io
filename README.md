### Visual Composition (Processing)<sup>Fall 2026||Prog-102-1</sup>

For this assignment, students were asked to create a character using the Java Processing Sketchbook.
![Initial State](https://trisssmithdaigle.github.io/compositionPartOne.png)

#### Initial Composition
The space creature in the foreground is created using a number of ellipses, circles, and Bezier Curves.
The Moon, Earth, and Sun are created from circles with hexadecimal colors and varying alpha values.
The star field in the Background is a random generation of over 2000 small circles in three separate distribution patterns in order to give the appearance of a galaxy as viewed from within its disk.

![Earth Is Pressed](https://trisssmithdaigle.github.io/compostitionPartTwo.png)

#### Interactive Composition
This composition, after further modification, became interactive, with the first image as the default state of the piece.
A logic statement is used to asses if the mouse is hovering over Earth when it is pressed. If this is the case, the following sequence occurs.
1. The earth disapears.
2. The central eye of the space creature appears to look at the user, via repositioning of the iris circle.
3. The text, "I was watching that" appears in the same color as the space creature
4. All the stars, including the sun, turn blood red. Simultaneously, the external tendrils of the space creature are changed from Bezier curves to lines, thus being straightened. The four radial eyes look at the user, via the same method as step 2. Finally, Bezier curves are used to give the central eye a blood-shot Appearance.

### Array and Function Practice<sup>Fall 2026||Prog-102-1</sup>

This creation demonstrates knowledge of recursive functions and object arrays.

![Practice Screenshot](https://trisssmithdaigle.github.io/functionArraysPracticeScreenShot.png)


#### Intention
The purpose of this program was to figure out how to use recursion to create shapes and patterns which change in size over time.
The result is a random distribution of circle patterns which expand in size and then retract.
This took way longer than necessary to get working, and indeed, it seems there are better uses for recursion.
